Bem-vindo ao **newhorizons**!

Este é o primeiro artigo do blog, criado para validar o fluxo estático de ponta a ponta:

1. **Escrita:** O autor escreve o texto puramente em formato Markdown (`.md`) com cabeçalho YAML (*front matter*).
2. **Transformação:** O Jekyll processa o Markdown, aplica o layout HTML (`_layouts/post.html`) e gera um arquivo HTML estático final em `_site/`.
3. **Deploy:** O GitHub Pages serve esses arquivos estáticos diretamente ao navegador, sem necessidade de banco de dados ou servidor backend complexo.

Tudo é simples, rápido e transparente.
