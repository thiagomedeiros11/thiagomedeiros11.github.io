Two Sum, the classic entry point for LeetCode.

People always debate whether LeetCode is actually necessary. Maybe you do not need it to land a job, though it helps for studying and understanding fundamentals. Still, if you ever run into it, it is better to know how to solve the problems.

___
<br>

My first thought was to use a simple loop over the array, but that quickly caused an issue.

Checking every pair against the target requires two nested `for` loops, which pushes the time complexity to O(n²).

Using a `Map`reduces the solution to `O(n)`. Instead of checking every possible pair, we can store the numbers we've already seen and check whether the current number's complement is already there.

For each number `nums[i]`, you calculate `target - nums[i]`. If that difference is already in the map, you found the pair.

### Here is an example:

`nums = [2, 7, 11, 15]`

`target = 9`


### First iteration

```ts
map = {}
i = 0
complement = 9 - 2 // 7
map.has(complement)? // false
```

Store the current value and index:

```
map.set(nums[i], i) // key: 2, value: 0
```

### Second iteration

```ts
map = { 2 => 0 }
i = 1
complement = 9 - 7 // 2
map.has(complement)? // true
```

The `complement`is already in the map, so the `if` condition is true and we return:

```ts
return [map.get(complement)!, i];
```

A quick breakdown of the return values:

`[]` returns an array.

`map.get(complement)` returns `0` (the key is 2, and its associated value is the index 0).

`i` is `1` (the index of 7).

`2 + 7 = 9`, which matches the target.

The problem asks for the indices of the two numbers, not the numbers themselves.

___
<br>
### Solution:

```ts
function twoSum(nums: number[], target: number): number[] {

let map = new Map<number,number>();

for(let i = 0; i < nums.length; i++){

    let complement = target - nums[i];

    if(map.has(complement)){
        return [map.get(complement)!, i];
    }

    map.set(nums[i], i);
}

return [];

}
```

This brings the solution down to `O(n)` since it only iterates through the array once.
